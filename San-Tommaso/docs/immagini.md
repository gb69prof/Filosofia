# Immagini

Le immagini principali sono state generate appositamente per questa PWA con lo strumento integrato di generazione immagini, usando la copertina fornita da gbprof come riferimento di atmosfera e sistema cromatico, non come tavola da sovrapporre all’interfaccia.

| File | Funzione | Formati |
|---|---|---|
| `tommaso-hero` | copertina: Tommaso nello studio e spazio per titolo HTML | WebP + JPEG |
| `mondo-tommaso` | panorama didattico con quattro hotspot | WebP + JPEG |
| `fumetto-01-06` | primi sei episodi biografici | WebP + JPEG |
| `fumetto-07-12` | dispute, Summa, silenzio e viaggio finale | WebP + JPEG |

## Vincoli dei prompt

- iconografia domenicana riconoscibile;
- architettura e abiti del XIII secolo;
- nessun testo incorporato, logo o filigrana;
- nessuna estetica fantasy o devozionale kitsch;
- blu profondo, pergamena e oro antico;
- dialoghi e informazioni sempre in HTML accessibile.

Le tavole narrative sono ricostruzioni, non documenti iconografici contemporanei a Tommaso. Le immagini non sono usate come prova storica.
